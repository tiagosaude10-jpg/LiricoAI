# Lírico AI

Lírico AI é um aplicativo desktop para transcrição inteligente de áudio e vídeo, com processamento local e suporte a múltiplos mecanismos de reconhecimento de fala.

## Recursos

- Transcrição de arquivos de áudio e vídeo
- Transcrição em tempo real pelo microfone
- Identificação e separação de falantes
- Exportação para TXT, SRT e VTT
- Suporte a Whisper e outros backends compatíveis
- Aceleração por GPU quando disponível
- Processamento local/offline em diversos fluxos

## Plataformas

### Windows

A versão para Windows é empacotada como `LiricoAI.exe` e instalador próprio.

### macOS

A versão para macOS será distribuída como `LiricoAI.app` e, posteriormente, em imagem `.dmg`.

### Linux

Há estrutura de empacotamento em AppImage em desenvolvimento.
